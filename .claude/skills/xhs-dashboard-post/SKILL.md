# 小红书看板爆文生成器

将任意数据看板或项目页面，自动转化为一套可发布的 **小红书图文内容**：爆款文案 + 高清配图 + 归档目录。

## 前置条件

- Playwright（`pip install playwright && playwright install chromium`）
- 目标看板 HTML 文件在本地可访问

## 执行流程

### 第 0 步：确认目标

向用户确认：
- 目标 HTML 文件路径（默认当前目录下的 `dashboard.html` 或 `index.html`）
- 是否需要启动本地 API 服务来加载动态数据
- 如果看板依赖 API 数据，先启动后端服务（如 `python app.py`）

### 第 1 步：分析看板功能

阅读目标 HTML 文件，提取以下信息：
1. **项目名称/标题** — 用于封面和文案
2. **核心功能**（3-5个） — 筛选逻辑、评分公式、视图切换、导出等
3. **技术栈** — 数据源、前后端框架、部署方式
4. **独特亮点** — 与其他工具的区别（如零成本部署、离线模式、手机适配等）
5. **数据字段** — 看板展示的列/指标名称

### 第 2 步：设计截图方案

根据功能分析，设计 5-7 张截图，每张对应文案中的一个核心段落。原则：**每张图讲一个独立亮点，图文一一呼应**。

截图方案通用模板：

| 序号 | 类型 | 内容 | 截取方式 |
|:--:|------|------|------|
| 1 | 封面主图 | 默认视图全貌，展示整体风格 | `full_page=True` |
| 2 | 核心功能特写 | 最亮眼的功能（如卡片、关键指标） | 视口截取首屏 |
| 3 | 第二视图 | 切换视图后的效果（如有表格/图表切换） | 点击切换后 `full_page=True` |
| 4 | 逻辑/公式面板 | 算法说明、筛选条件、配置项 | 视口截取头部 |
| 5 | 交互演示 | 搜索、排序、筛选等操作后的效果 | 操作后截取 |
| 6 | 最佳结果 | 按推荐排序后的 Top 结果 | 排序后截取 |
| 7 | 移动端/导出（可选） | 响应式效果或导出功能 | 视口截取 |

**截图脚本模板**：见同目录下的 `screenshot_template.py`，复制到目标项目后按需定制。

**关键参数**：
```python
VIEWPORT_WIDTH = 750          # 小红书最佳宽度
device_scale_factor = 2        # 2x 高清
```

### 第 3 步：撰写小红书文案

按以下结构生成爆文文案：

```
[标题] — 吸引眼球，15-30字，含 Emoji 和核心数字
[开头] — 1-2句人设/故事引入，制造共情
[核心功能] — 3-5个小标题，每段 3-5 句，口语化
[技术栈] — 逐行列举，简洁展示
[使用心得] — 3-5条实用建议，个人化语气
[适合人群] — 3-5条，✅列表
[结尾] — 风险提示/互动引导
[标签] — 8-12个，混用大词 + 精准词
```

**写作规范**：
- 语气：亲切有趣，像朋友分享，用"我""姐妹们""宝子们"
- Emoji：每段 2-4 个，不堆砌，用 Emoji 区分小标题
- 分段：多用小标题和短段落，手机端易读
- 数据：露出具体数字（如"5500→27只""股息率>5%"）
- 标签：混用大词（#Python）和精准词（#股息率选股）

**输出格式（重要）**：
- post.md 必须是纯文本，不能含任何 Markdown 符号
- 禁止：`#` `##` `###` 标题标记、`**粗体**`、`---` 分隔线、`` ``` `` 代码块、`| 表格 |` 语法
- 标题用 Emoji 区分，代码块用缩进表示，表格用逐行列举
- 小标题格式：`🎯 标题文字`（Emoji + 空格 + 文字）
- 段落之间用两个空行分隔
- 确保用户全选复制后可直接粘贴到小红书发布框

### 第 4 步：执行截图

1. 复制 `screenshot_template.py` 到目标目录，命名为 `screenshot_xhs.py`
2. 根据第 2 步方案，编辑 `SHOTS` 列表，每张图配 `setup` 函数
3. 先后步骤：启动本地 HTTP 服务 → Playwright 逐张截图 → 每张独立导航，互不污染
4. 运行 `python screenshot_xhs.py`
5. 确认 5-7 张图全部生成且清晰

**常见问题**：
- 如果 `playwright install chromium` 还没跑，先执行安装
- 截图脚本遇到 Windows GBK 编码报错，在开头加 `sys.stdout.reconfigure(encoding='utf-8')`
- 每张截图前 `page.goto(url)` 重新加载，确保状态独立（搜索/排序不影响下一张）

### 第 5 步：归档输出

创建 `xhs_archive/` 目录：
```
xhs_archive/
├── README.md              # 归档索引 + 发布建议（平台、图片顺序、首图建议）
├── post.md                # 完整爆文文案（纯文本，可直接复制发布）
├── image_mapping.md        # 图片与文案段落对照表（方便发布时参考）
├── screenshot_xhs.py       # 本项目截图脚本副本（下次更新数据可复用）
└── images/                 # PNG 配图（1500px宽, 2x高清）
    ├── 01_xxx.png
    ├── 02_xxx.png
    └── ...
```

**归档文件说明**：
- `README.md`：记录来源项目、生成日期、图片列表、发布建议
- `post.md`：纯文本文案，全选复制即用
- `image_mapping.md`：表格列出每张图 → 对应文案哪段、展示了什么功能

## 常用截图操作参考

```python
# 切换视图
page.click("button.btn-view:nth-child(2)")  # 表格按钮

# 搜索筛选
page.fill("#q", "关键词")

# 排序
page.select_option("#sort", "b")  # 按某列排序

# 展开/收起面板
page.click("#toggle_btn")

# 移动端视口
page.set_viewport_size({"width": 375, "height": 812})

# 等待渲染
page.wait_for_selector(".card", timeout=10000)
page.wait_for_timeout(1000)
```

## 实战案例

以下为真实执行过的高股息看板案例，可作为新项目的参考模板。

### 项目背景
- 项目名：高股息筛选看板
- 核心功能：从 A 股 5500 只中筛出市值 > 500 亿 + 股息率 > 5% 的股票，附带三因子买入权重评分
- 技术栈：Tushare + Baostock → Python API → 原生 HTML/CSS/JS → GitHub Pages

### 6 张截图设计

| 图序 | 文件名 | 截图操作 | 对应文案段落 |
|:--:|------|------|------|
| 1 | `01_cover_card_grid.png` | 默认卡片网格，全页长图 | 封面 — 第一印象 |
| 2 | `02_card_closeup.png` | 视口截首屏 750×900，聚焦卡片细节 | 「卡片模式」— 股息率绿色大字 + 买入权重进度条 |
| 3 | `03_table_view.png` | 点击表格按钮后全页截图 | 「切到表格模式」— 全部数据列一览 |
| 4 | `04_formula_toolbar.png` | 视口截头部 750×600 | 「买入权重公式」— 三因子打分逻辑 |
| 5 | `05_search_filter.png` | fill "银行" 后全页截图 | 「搜索筛选」— 实时过滤演示 |
| 6 | `06_buy_weight_sorted.png` | select_option "买入权重↓" 后视口截首屏 | 「权重排序」— 综合评分最优标的 |

### 文案亮点模式
- 标题：「我用 Python 搭了个 XX 看板，白嫖 GitHub 部署，真香！」— 身份标签 + 核心亮点 + 情绪词
- 开头：制造身份共鸣（"又菜又爱玩的股市小白"）+ 痛点（"翻半天软件"）+ 行动（"一怒之下自己写"）
- 功能段：每段配一张图，Emoji 小标题 → 一句话概括 → 细节展开 → 情绪收尾
- 心得段：4 条，每条有具体数字或操作建议，不空洞
- 结尾：风险提示 + 互动引导（"你们平时怎么 XX 呀？评论区聊聊～"）

## 注意事项

- 如果看板依赖后端 API，先确保 `python app.py` 在运行
- 数据敏感的项目，文案加「仅供参考，不构成投资建议」
- 截图前清空搜索框、重置排序，每张图 `page.goto(url)` 重新加载确保状态独立
- 首图（封面）最重要，确保信息量足且颜值高，可建议用户用修图 APP 在封面加标题大字
- **post.md 必须是纯文本**：不含 `#` `**` `---` 等 Markdown 语法，方便直接复制到小红书
- 图片尺寸统一为 1500px 宽（750×2x），发布时无需缩放
