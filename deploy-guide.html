📊 高股息筛选看板

从零到手机桌面 · 小白也能看懂的完整部署教程

🎯 这是什么？

一个自动筛选 A 股高股息股票的网页看板。它每天自动从 Tushare 和 Baostock 拉取数据，帮你找出：

  • 市值 > 500 亿的大型公司
  • 股息率 > 3% 的高分红股票
  • 股价接近一年低点（< 15%）的低估机会
  • 股价接近布林带下轨（< 15%）的技术买点

部署后可以在电脑浏览器、手机浏览器上访问，还能添加到手机桌面像 App 一样使用。

🚀 部署 Render（核心步骤）

1 Fork / 上传项目到 GitHub

把整个项目文件夹上传到你自己的 GitHub 仓库。确保这些文件都在：

├── app.py              # 后端 API 服务
├── dashboard.html       # 前端看板（主要页面）
├── index.html           # GitHub Pages 副本
├── gh_update.py         # 定时更新脚本
├── render.yaml          # Render 部署配置
├── requirements.txt     # Python 依赖
├── manifest.json        # PWA 配置
├── sw.js                # Service Worker
├── screen_icon.png      # 图标
├── icon-512.png         # PWA 大图标
├── .nojekyll            # GitHub Pages 配置
├── cache/               # 数据缓存目录
└── .github/workflows/   # GitHub Actions 定时任务

2 在 Render 创建 Web Service

  1. 打开 dashboard.render.com
  2. 点 New + → Web Service
  3. 连接你的 GitHub 仓库（授权 Render 访问）
  4. 选择项目仓库后，Render 会自动读取 render.yaml

3 配置环境变量

在 Render 的 Environment 标签页添加：

变量名值说明
TUSHARE_TOKEN你的 Tushare Token获取股息数据
PUSHPLUS_TOKEN你的 PushPlus Token微信推送通知
PORT8080服务端口
RENDERtrue标识 Render 环境
⚠️ 关于 Tushare IP 白名单：
免费 Tushare token 通常绑定了你注册时的 IP。如果在 Render 上调用 Tushare API 失败（update_dv&val 报错），数据会自动回退使用本地缓存的 parquet 文件。建议定期在本地运行 gh_update.py 更新缓存后 push 到 GitHub。

4 选择实例类型

选择 Free（免费计划）即可：

  • 每月 750 小时运行时间（够用）
  • 15 分钟无访问会自动休眠（再次访问会自动唤醒，约 30 秒）
  • 休眠期间数据不丢失

5 点击 Create Web Service

Render 会自动：

  1. 克隆你的 GitHub 仓库
  2. pip install -r requirements.txt 安装依赖
  3. python app.py 启动服务
  4. 分配一个 https://xxx.onrender.com 域名

等待 3-5 分钟构建完成，看到 "Your service is live" 就成功了！

⏰ 设置 GitHub Actions 定时推送

项目已包含 .github/workflows/daily_update.yml，每个工作日 15:30（北京时间）自动运行：

  1. 拉取 Tushare 股息数据
  2. Baostock 实时股价
  3. 通过 PushPlus 推送微信汇总

需要在 GitHub 仓库的 Settings → Secrets and variables → Actions 添加：

Secret 名称值
TUSHARE_TOKEN你的 Tushare Token
PUSHPLUS_TOKEN你的 PushPlus Token
💡 提示：Actions 只会发微信推送，不会往仓库 push 代码，避免和手动推送冲突。

❓ 常见问题

Q: Render 打开很慢？

免费实例 15 分钟无访问会自动休眠，再次访问需要约 30 秒唤醒。可以开定时 ping 服务（如 uptimerobot.com 每 5 分钟访问一次）保持活跃。

Q: 手机上看 K 线图太小？

K 线图响应式适配屏幕宽度。手机竖屏一列一张卡片，横屏两列。

Q: update_dv&val 报错？

这是因为 Render 的 IP 没在 Tushare 白名单里。数据会自动回退使用本地缓存。建议每周在本地运行一次 python gh_update.py 然后 push 到 GitHub。

Q: 数据不更新？

点 Update Price（紫色按钮）拉取 Baostock 实时数据。如果还是旧的，检查浏览器缓存（Ctrl+Shift+R 强制刷新）。

Q: 如何修改筛选条件？

编辑 app.py 开头的这几个变量：

DIVIDEND_THRESHOLD = 3.0   # 最低股息率
MIN_MARKET_CAP = 500       # 最低市值（亿元）
MAX_PCT_FROM_LOW = 15      # 距1年低点最大百分比
MAX_PCT_FROM_LOWER = 15    # 距BB下轨最大百分比
