方案一：GitHub 全自动部署 免费 推荐

适合谁？ 不想依赖电脑开机、希望手机随时看最新数据的人。

原理：GitHub 提供免费的定时任务服务器，每天自动拉数据、更新网页、推送微信。

部署步骤

总耗时约 10 分钟，只需要操作一次。

第 1 步：打开仓库设置页面

浏览器打开：
https://github.com/edison19490901-netizen/dashboard-of-high_divided_screen/settings/secrets/actions

（如果打不开，说明需要先登录 GitHub 账号。没有的话去 github.com 免费注册一个。）

第 2 步：添加 Tushare Token

  1. 点页面上的 New repository secret 按钮
  2. Name 填：TUSHARE_TOKEN
  3. Value 填：你的 Tushare token（一串字母数字）
  4. 点 Add secret
⚠️ Tushare token 是什么？ 去 tushare.pro 注册，登录后在「个人主页 → 接口Token」里复制。

第 3 步：添加 PushPlus Token（可选，需要微信推送才做）

  1. 再点 New repository secret
  2. Name 填：PUSHPLUS_TOKEN
  3. Value 填：你的 PushPlus token
  4. 点 Add secret
💡 PushPlus token 怎么获取？ 打开 pushplus.plus → 微信扫码登录 → 首页就能看到 token。不需要微信推送可以跳过这一步。

第 4 步：手动触发一次测试

  1. 打开 Actions 页面
  2. 左侧点 Daily Dashboard Update
  3. 右侧点 Run workflow → 绿色 Run workflow 按钮
  4. 等待 1-2 分钟，看到绿色 ✅ 就成功了

第 5 步：手机验证

手机浏览器打开：
https://edison19490901-netizen.github.io/dashboard-of-high_divided_screen/

看到数据就说明部署成功！🎉

✅ 完成！ 之后每个工作日 15:30 自动更新，什么都不用管。看板地址可以加到手机桌面，像 App 一样用。

方案二：本地 Windows 定时任务 本地电脑

适合谁？ 电脑平常不关机、想做 GitHub Actions 的备份方案。

原理：Windows 自带的任务计划程序每天定时跑 Python 脚本，拉数据后推送到 GitHub。

前置准备

  1. 安装 Python：去 python.org 下载安装（安装时勾选 ✅ Add Python to PATH）
  2. 安装依赖：打开命令提示符（Win+R → 输入 cmd），粘贴以下命令： 
    pip install tushare baostock pandas pyarrow python-dotenv
  3. 配置 Token：在项目目录创建 .env 文件，内容： 
    TUSHARE_TOKEN=你的tushare token
PUSHPLUS_TOKEN=你的pushplus token

安装定时任务

  1. 右键开始菜单 → Windows PowerShell (管理员)
  2. 粘贴以下命令并回车： 
    & "D:\Claudeee\highDivided_highValue_lowPrice\网格高市值高股息率\2%-3%看板识股\setup_task.ps1"
  3. 看到绿色 === Task Created === 就成功了

手动测试

schtasks /run /tn HighDividendDailyReport

等 30 秒后查看日志：

type "D:\Claudeee\highDivided_highValue_lowPrice\网格高市值高股息率\2%-3%看板识股\auto_report.log"

修改定时时间

编辑 setup_task.ps1 第 17 行：

$trigger = New-ScheduledTaskTrigger -Weekly -DaysOfWeek ... -At 15:30
                                                         # 改这里 ↑

改完后重新以管理员身份运行安装命令。

定时任务管理

🔕 禁用
Disable-ScheduledTask -TaskName HighDividendDailyReport
🔔 启用
Enable-ScheduledTask -TaskName HighDividendDailyReport
🗑️ 删除
Unregister-ScheduledTask -TaskName HighDividendDailyReport -Confirm:$false

也可以用图形界面：Win+R → taskschd.msc → 搜索 HighDividendDailyReport

电源设置（重要！）

否则电脑休眠时任务不会执行：

Win+R → powercfg.cpl → 当前计划 → 更改高级电源设置 → 睡眠 → 允许唤醒计时器 → 启用

常见问题 FAQ

两个方案有什么区别？我该选哪个？

方案一（GitHub）：不用开电脑，完全免费，推荐首选。
方案二（本地）：数据存在自己电脑上，可作为方案一的备份。
可以两个都部署，互不影响。

为什么微信没有收到推送？

1. 确认已添加 PUSHPLUS_TOKEN 密钥
2. 去 pushplus.plus 确认 token 正确
3. 关注 PushPlus 公众号才能收到消息

看板数据怎么没有更新？

1. 打开 Actions 看最近一次运行状态
2. 如果是红色的 ❌，点进去看错误日志
3. 常见原因：Tushare token 过期或当日 API 调用次数用完

能改成其他时间更新吗？

方案一：编辑 .github/workflows/daily_update.yml 第 6 行 cron 表达式。
注意 GitHub 用的是 UTC 时间，北京时间 = UTC + 8。
方案二：编辑 setup_task.ps1 第 17 行，重新运行安装命令。

看板能在手机上像 App 一样用吗？

可以！打开看板地址后：
iPhone：Safari → 底部分享按钮 → 添加到主屏幕
Android：Chrome → 右上角菜单 → 添加到主屏幕
